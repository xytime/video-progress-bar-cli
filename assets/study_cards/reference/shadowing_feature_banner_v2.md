# Shadowing Feature Card v2

`shadowing_feature_banner_v2.png` is a static reference only; it is not wired into any rendering or publishing path.

## Reusable fields

- `DAY 01`: daily sequence; replace only the number.
- `B1`: level slot; use a CEFR level (A1--C2) or the agreed learning level.
- `30s CHALLENGE`: task badge; the duration can change without changing the card structure.
- `影子跟读 / SHADOWING`: fixed, two-language recognition anchor.
- `LISTEN → REPEAT → SPEAK`: fixed training loop / long-term slogan.

The image-generation pass supplied only the text-free navy-and-gold background. All Chinese (and all task-copy) in the final reference is rendered as deterministic SVG text before PNG export, so the copy is legible and replaceable rather than model-generated pseudo-text.
