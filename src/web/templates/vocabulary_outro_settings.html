启用范围

适用于主流水线追加的生词片尾。独立制作的英语世界学习卡已有随片词卡，不经过本步骤；这里不改变学习卡的内容和时长。

每页 3 个生词，每页 3 秒。启用后如全片零生词，会独立补提取并校验；处理失败会记录异常并阻止该任务静默跳过片尾。

类型识别条件

英语世界优先按内容类型识别；华尔街、TED、AI 资讯按来源频道匹配。AI 也接受显式主题 AI。其余归入“其他”。这里的设置独立于商品挂载和公众号文章。

请输入完整 UC 频道 ID，多个 ID 用逗号或换行分隔；同一频道不能归入多个类型。
