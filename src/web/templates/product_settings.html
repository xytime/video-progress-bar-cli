下载导入格式示例

将示例占位内容替换为采集资料：account_id 是后台稳定账号标识；captured_at 为含时区的采集时间；total_pages、total_items 来自后台总数；pages 覆盖 1 到总页数。商品 ID 用字符串，title 保留完整名称，stock 为整数或 null（未知）。缺页、重复或名称冲突会拒绝导入。

视频类型

全局默认商品

识别条件与其他类型细分

英语世界使用任务内容类型；下列来源频道按完整 ID 匹配，多个 ID 用逗号分隔。AI 也接受显式主题 AI，“科技”分类不会自动归入 AI。

“其他”中的财经、新闻仍优先使用原有细分规则；没有命中时使用上方“其他”一行。

首选、备选、全局默认去重后必须都能在次数上限内尝试。
