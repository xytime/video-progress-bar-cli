## 结论

自动化不能依赖“多试几次”。本次问题分属候选发现、封面异步状态、封面质量、管理页解析、回查调度及本机文件系统六层。它们必须分别处理。提交受理、管理页已发布和本地状态是不同证据，不能互相替代。

本次实现不调整每日发布额度，也不新增交易时段发布限制；回查预算仅约束只读操作。

## 已证实问题及处理

| 问题 | 证据和原因 | 程序处理 |
| --- | --- | --- |
| 双封面保存后仍报缺失 | 平台检测异步刷新，旧提示与新缩略图短暂共存 | 等待明确成功态；缺失提示仅触发一次重新检测；违规/质量失败仍停止 |
| 财经横封面被拒 | 油价作品平台明确提示“封面边框面积过大” | 优先独立横封面；有哈希匹配的原创无字底图时重新排版 4:3，不给带字竖海报补边 |
| 英语世界 QUEUED 长期不被领取 | 发现 SQL 只选“尚无下游账本”，漏掉已排队项 | 同时发现未建账与 QUEUED；已受理、未知和取消记录不自动复活 |
| 管理页查不到刚发布作品 | SPA 搜索框尚未加载；长简介超过旧 320 字截断窗口 | 等待搜索框；按身份锚点之后的编辑菜单、日期及紧邻状态判断，不把正文或下一作品状态当证据 |
| 管理页不断弹窗 | 可见浏览器、零间隔、无界旧记录回查叠加；解除熔断时没有先限制回查范围 | 通用及英语世界自动回查固定后台运行；通用默认每轮最多 2 次，零/负值不再解释为无限 |
| 同一作品每分钟反复查 | 调度器每分钟新进程，内存等待无法跨巡航生效 | 通用作品预约写入 SQLite，默认 600 秒冷却；冷却项不占批次名额；预约不修改投稿状态 |
| 失败证据指向旧页面 | 多个作品写入共享校准目录，无法证明当前失败 | 通用投稿按尝试 ID 隔离；自动回查按作品 ID/时间隔离，错误只引用本次目录 |
| 油价任务启动后中断 | ticket 已消费；原进程文件句柄显示 revoked；无本次提交回执，标题回查未匹配 | 保留 UNCERTAIN，不凭进程消失、文件缺失或搜索无匹配而重传；尚未证明磁盘句柄失效的物理原因 |

## 自动处理决策

| 观察到的状态 | 可自动执行 | 不可执行 |
| --- | --- | --- |
| 本地素材、封面准备异常 | 若 DAL 确认启动凭据未消费，原子取消领取；否则保留未知并告警 | 异常冒泡后遗留假 UPLOADING；直接把未知任务重新入队 |
| 检测进行中、旧缺失提示 | 有限等待；一次重新检测 | 无限点击检测或反复上传 |
| 用户授权的检测拥挤提示 | 仅对“作品检测失败 + 当前检测人数过多 + 请稍后再试”的完整组合沿用授权例外 | 把封面违规、质量失败、其他红黄提示也当拥挤跳过 |
| UNDER_REVIEW | 冷却后只读核验，后台运行并保存独立证据 | 重传同一成片 |
| UNCERTAIN / 启动后证据丢失 | 独立只读核验；必要时交接具体作品和缺失证据 | 根据“不在第一页”或“进程已退出”推断未提交 |
| 明确已发布 | 按对应作品落账，避免重复投递 | 使用其他作品、其他平台或本地测试的成功代替 |
| 持久 UI 熔断 | 保留现场；有新校准证据再解除；先小批后台观察 | 反复清熔断，立即扫描全部旧记录 |

## 生效配置与代码入口

- `src/config/settings.py` / `.env.example`：`DOUYIN_REVIEW_MAX_PER_RUN=2`、`DOUYIN_REVIEW_INTERVAL_SECONDS=600`。非正数批量值回退 2；冷却最少 60 秒，零值回退 600。
- `PipelineDB.reserve_douyin_reconciliation_slot`：事务检查 UNDER_REVIEW 后预约，跨进程共享冷却；其他状态不允许自动回查领取。
- `PipelineManager.reconcile_douyin_under_review`：按实际预约成功次数计预算，证据写入 `output/douyin_reconciliation/<publication_id>/<timestamp>/`。
- `scripts/run_publication_window.py`：英语世界自动管理页回查不再继承投稿的可见浏览器设置；其原有独立回查节流仍保留。
- `PipelineDB.get_douyin_publication_launch_status`：只读查看当前尝试启动时间和注销记录，不返回 token 或其摘要。

## 验证方法

使用项目虚拟环境；测试不会上传视频或发送真实 Telegram 消息：

```sh
PYTHONPATH=src .venv/bin/python -m pytest tests/unit/test_douyin_native_cover.py tests/unit/test_douyin_uploader.py tests/unit/test_douyin_pipeline.py tests/unit/test_douyin_publications.py tests/unit/test_douyin_ui_guard.py tests/unit/test_english_world_jobs.py tests/unit/test_publication_window_runner.py -q
```

重点回归：无窗口且只读的命令；重启后冷却仍有效；时钟回拨不触发忙循环；冷却项不饿死后续项；零值不无界；已发布/未知项不能领取；独立证据目录；长简介及相邻作品不能误判；横封面准备异常不启动上传器。

生产验收必须另外核对当前进程参数、配置指纹、DAL 状态和管理页证据。单测通过不等于已公开，也不证明长期无人值守已经验证。
