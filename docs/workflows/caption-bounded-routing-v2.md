# 首中尾有界字幕分流 v2

2026-11-01 用户明确要求修改并立即上线。本规格取代 v1 的负向全片回退规则。

- 目的：判断是否生成中文字幕，不以逐帧 OCR 转写英文对白。
- 有效 ASR 时间轴的首、中、尾各15秒，1 fps，最多45帧；短片合并重叠窗口。
- 所有窗口无任何中文 OCR 行：GENERATE，继续现有翻译、字幕质量检查和渲染；不得声称全片无中文。
- 有中文：使用实拍帧语义核验。标题/姓名牌等 NOT_DIALOGUE 可以生成；连续对白字幕 MATCH 可保留。窗口混合则复核。
- UNCERTAIN/PARTIAL/ABSENT 每窗口最多一次6帧定向补查；上限63帧。仍不明确则 REVIEW，不全片回退、不无限重试。
- OCR/解码/认证/网络/无效响应错误不能成为负向结论。缺帧、缺窗口、低置信中文均不得静默放行。
- 已有效最终决定优先复用；未完成旧扫描文件保留，但不能强制触发整片 OCR 或语义核验。
- 接受抽样可能漏掉未抽区域局部字幕的风险；凭证 full_timeline_verified=false。完整 ASR 审核正文、字幕质量阈值、会话锁和未知投稿保护不变。
- 验收：负向45帧直接生成；中文保留、繁简双语、局部/异常复核；缓存变更失效、中断恢复、旧凭证兼容；隔离回归通过；真实英文样本记录冷 OCR 次数及耗时。不能把复核/失败增加算作吞吐提升。
- 生产范围：native_caption_sampling_enabled=true 的普通字幕分流；既有渲染/提交任务不重投。回滚该开关关闭恢复旧完整检查，不删除检查点。
