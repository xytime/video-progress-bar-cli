## 已明确的流程

程序调度 → AGY CLI 生成候选 → 独立 AGY CLI 看图核验 → 项目排版及来源校验 → 正常后续流程。AI 生成或核验失败达到三次上限或截止时间，自动使用既有本地专属封面兜底；兜底也失败才挂起。

- 取消 OCR 字符数为零的限制，生产封面不依赖 OCR。生成提示词提示避免非英文文字；英文、数字及 OCR 噪声都不作为拒收条件。项目负责叠加最终中文标题。
- 图片核验只设实际质量底线：主题相关、主体可辨认、构图完整、细节充分、没有严重渲染损坏；拒绝空白、极简占位图、明显粗糙低质量产物。不能实际看图或回执不完整时不冒充通过，重试或本地兜底。
- 生图与核验均由程序调用 AGY CLI，使用独立会话，绑定图片 SHA-256 与任务编号；不调用 Codex CLI、Codex 图像工具或其他模型 API 作为备用。停用遗留定时入口中的 Codex 执行分支。AGY 自身额度与可用性仍受其服务限制。
- 最多三次 AI 生成，每次独立记录失败阶段与稳定原因；失败反馈进入下次提示词。超时清理进程组，锁期限覆盖生图、复核和收尾预算。兜底独立于 AGY 服务运行，记录 `deterministic_fallback`，不冒充 AI 成功。
- 保护无关 topic_clues 工作及旧发布证据。旧 AGY 挂起任务不因升级自动批量回队；本条 `AC2_Jw44hJI` 先在隔离目录完成新规则复核与封面生成，生产回队可能触发提交，作为最后单独确认步骤。

## 验收

1. 真实 AGY 复核今晚被 OCR 拒收的底图；另以粗糙样本验证拒收，以可用英文元素样本验证不因文字拒收。生成器自述不能作为复核回执。
2. 隔离测试验证质量拒收、缺回执、图片哈希变化、三次上限、超时回收、并发锁、截止兜底、兜底失败、迟到结果及已有提交保护。既有提交不得被回队。
3. 至少六个完整影子任务覆盖财经、科技与国际议题；财经不少于三个。至少五个在三次内完成 AI 路径，余项必须在限定时间内形成合格兜底或明确失败。强制 AI 不可用时实测本地兜底与数据库恢复；测试和现场生成分别报告。
4. 核实调度入口没有 Codex 调用，核对运行日志及质量回执。测试通过、提交推送、运行采用、封面恢复和平台投递分别报告。
