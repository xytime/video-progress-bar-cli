## Review 结论与修复

| 原问题 | 影响 | 已实现 |
| --- | --- | --- |
| 高互动入口隐藏普通任务的处理操作 | 无法直接启动、重试或复核 | 根据服务端当前资格显示对应按钮 |
| “已处理”实际只写浏览标记 | 容易把看过误认为加工完成 | 改为“已浏览”，保留独立浏览筛选 |
| `PENDING` 混合低分、未评分、待加工和成片就绪 | 无法判断为何没有继续处理 | 显示明确阶段、解释及动态入队分数线 |
| `FAILED` 混合技术失败和规则拦截 | 容易对规则拒绝直接重试 | 分别显示“处理失败／重试处理”和“规则拦截／复核放行” |
| 空审查标签显示“未命中敏感词” | 没有审计证据却被理解成已通过 | 改为中性的“审查未核验” |
| 手机卡片把 `SUBMITTED_BOUND` 归为“已发布成功” | 把提交受理误认为公开发布 | 高互动卡片仅依据确认记录展示发布完成 |

## 可审查行为

| 当前阶段 | 主要操作 |
| --- | --- |
| 仅供选题、待评分、未达入队分数 | 人工选用并入队 |
| 待加工 | 开始处理 |
| 处理失败 | 重试处理 |
| 规则拦截 | 复核放行，沿用既有审计与 P0 双确认 |
| 加工中、平台审核中、已提交待确认、发布记录待核实 | 查看详情，禁止从此入口重复启动 |
| 成片就绪且本地文件存在 | 查看成片、查看详情 |
| 已拆分加工 | 查看分集 |
| 等待登录 | 前往登录、查看详情 |

所有行保留原视频链接和独立浏览标记。新阶段筛选在数据库分页前执行，列表数量与翻页保持一致，旧状态 URL 仍兼容。

“人工选用并入队”明确说明会转为手动任务、评分设为 100 并锁定。启动前说明沿用现有流程，后续可能自动发布。低于既有重试接口 75 分线的失败任务，重试只恢复待筛选，界面明确提示。

## 操作保护

- 点击携带任务版本，服务端重新核实状态、分数、来源、人工复核标记及平台记录。旧按钮或不匹配动作返回 409。
- 同视频人工操作使用非阻塞文件锁，避免跨线程、跨进程的重复恢复请求交错执行。
- 请求期间禁用按钮；提交后列表读取失败时不重新启用旧按钮。
- 已有平台记录、正在加工、待人工复核等任务不提供重复入队操作。
- 本地视频只按任务 ID 查找固定产物路径，拒绝越界路径及指向输出目录外的符号链接。
- 没有新增数据库表、自动处理规则或发布任务。测试中的处理调用全部替换为记录调用的桩。
