# 视频预筛选：静态页面方案 v1

2026-10-21；业务范围与页面视觉已由用户确认，已授权开发。整理者 Codex，具体模型版本未知；设计稿生成器 Superdesign / gemini-3.1-pro。

确认规格：[video-prefilter-v1.md](../../specs/video-prefilter-v1.md)。

## 评审重点

- 独立“视频预筛选”tab，放在选题中心，与已有素材列表和关键词采集并列。
- 上方配置、下方结果；默认 48 小时 / 最长 300 秒 / 播放量至少 10,000 / 点赞率至少 1.5% / 最多 50 个候选。
- 关键词每行一个短语，任一匹配；保存规则与开始检索是两个独立操作。
- 合格、未达标、资料不足、请求失败分别可查；结果默认按播放量降序。
- 操作限收藏、排除与查看原视频；没有生产提权、入队或发布入口。

## 交互状态（本轮只呈现静态样式）

| 状态 | 正式开发后的行为 |
|---|---|
| 尚未检索 | 配置可编辑，结果区提示手动开始；没有虚构的上次成功记录 |
| 修改未保存 | 保留参数草稿；保存后才能开始新检索 |
| 检索中 | 展示搜索/读取详情阶段及已处理数量，禁用重复启动 |
| 成功但无合格 | 显示候选数、各项淘汰原因；不自动放宽门槛 |
| 部分失败 | 保留已读结果，单列失败数量和原因；不声称全面完成 |
| 完全失败 | 错误与旧结果明确分开；不显示“本轮零结果”冒充成功 |
| 配额或门禁阻止 | 配置仍可保存；搜索不可用及原因可见 |
| 保存冲突或失败 | 保留当前草稿，提供重新载入/恢复指引 |

## 静态稿限制

所有视频标题、频道、统计、时间、额度和状态都是虚构示例。该稿不验证 API、保存、筛选、收藏或生产隔离功能；这些须在页面确认后实现和验收。

本轮没有改动产品代码、数据库或运行配置。静态 HTML 只含展示 HTML/CSS，不接业务接口。
