# 英语世界连续未交付故障：2026-10-20

目标是让下一轮自动生产避开已确认不能制作的候选，保留可用来源，并明确区分供应商故障、
内容拒绝、制作完成、已提交和公开发布。本文记录代码修复及现场验证，不授权修改历史审校结果。

## 根因与修复

| 故障 | 影响 | 修复 |
| --- | --- | --- |
| AGY CLI 实际生成返回 `location ineligible`，应用可用不能证明 CLI 可用 | 初稿、独立审校及视觉审核停产 | 已加入真实生成预检、AGY/Codex CLI 有界切换、原任务共享预算与独立会话；无付费 API |
| 原任务已终止或预算耗尽，自动选题仍反复选中 | 下载与转写后才拒绝，持续浪费名额 | 默认片段索引仅保存原输入身份；每轮选题前回读原审校账本，不缓存资格、不清零计数 |
| 先截取前 20 个结果再排除；重叠搜索返回重复来源 | 被排除项目和重复项目挤掉可用候选 | 先排除、去重后限额；同优先级按真实上传日期从新到旧排列 |
| 本轮后续成功时丢失此前候选淘汰记录 | 下一轮又选中已明确不合格的来源 | 成功请求与失败请求均携带来源淘汰记录 |
| 制作预检最多 10 项，交付协议仅接受 8 项 | 全部候选失败时，连失败回执也可能写不出 | 制作端、记录端、读取端共用 10 项上限；第 11 项仍拒绝 |
| 未知子进程、磁盘或权限错误被当作来源质量问题 | 合格来源被错误排除 | 只凭退出码不能淘汰来源；内部故障停止并留回执，启动阶段异常也留下机器回执 |
| 早期筛选仅做关键词匹配，存在同义表达、隐含政治语境 | 制作完整视频后才被最终审核拦截 | 翻译和渲染前独立阅读标题与冻结英文全文；早期与最终检查共用既有内容安全政策，最终全文和画面审核保留 |

`output/english_world_language/candidate_admissions/<YouTube ID>.json` 是调度索引，
原 `tasks/<task identity>/language_attempts.json` 仍是权威账本。
索引损坏停止选题；不存在原任务则视为新任务；原账本资格变化立即反映。
自动选题跳过的是该来源已观察到的默认片段。具名恢复不受此提前避让影响，但仍必须通过
下载后的精确输入准入；换目录、换模型或指定来源都不能获得额外预算。

早期语义审查单独记录输入/政策指纹和实际供应商回执，复用有界 CLI 路由：
同输入同阶段最多两次、每个供应商一次，只有技术故障才切换。明确内容拒绝可继续下一候选；
覆盖不足、结果自相矛盾或供应商故障停止，不误记为来源违规。
早期 PASS 仅表示候选文本可进入制作，不能代替成片安全检查，也不授予投稿资格。

## 运行与剩余边界

日更进程从当前主干工作区启动，下一次新进程会读取本次代码和索引。

回归、账本回放与平台公开状态分别验收。真实后续日更仍可能遇到新来源质量问题、
网络失败或平台审核；应根据阶段证据处理，不能以无限重试或放宽安全规则掩盖。

本次没有修改历史 QA、历史调用次数、内容放行政策、已受理投稿或平台状态。
