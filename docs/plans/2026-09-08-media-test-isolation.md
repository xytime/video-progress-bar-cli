# 媒体测试隔离与实际产物验收

目标：补齐既有 8 项媒体测试，保持真实 Whisper、FFmpeg 和 DragonEye 渲染，网络关闭、生产数据不可读写。此阶段不等于全部重构工作完成。

## 三道闸门与计划
- 边界：独立 worktree；改动测试工具、测试、文档与原创合成语音夹具。无正式 output/凭据输入，无发布、交易、重启。
- 正交：`--media` 仅准备离线模型，`--browser` 仅准备浏览器；业务设置与生产处理器不接收测试分支逻辑。
- 复杂度：新增 Python 文件小于 300 行；runner 维持小于 300 行、函数约 60 行以内。大型 caption_processor 原计划不扩展；实际媒体复现空字幕后，仅增加纯函数调用与历史记录。
- 先做独立探针，验证已安装 Whisper 的 XDG 缓存契约与 Playwright 的浏览器路径契约；失败保留真实退出，不以 skip 代替。
- 固定合成语音由本机系统语音一次生成，记录文本、工具、语音、采样参数与 SHA；执行测试不依赖 say 服务。
- 仅复制 tiny/base 两个已安装模型，按已安装 Whisper 元数据校验 SHA；未知布局、缺失或坏模型明确拒绝，不联网下载。
- 字幕用 tmp_path；明确关闭在线翻译以验证转录/烧录，保留默认在线翻译的单元覆盖。检查全文词序、事件时间、音视频流、帧上字幕与产物散列。
- 研报用生产渲染器与本地品牌资源生成 PNG/PDF，检查正文/图像资源、尺寸并目视验收。
- 先定向运行再全量测试；自审 immutable diff、接口/边界/失败路径、依赖与产物收据。流水线空闲后合入并 push；正式 checkout 用同一隔离入口再次验收，回读服务和进程。

## 已复现缺陷与范围调整

`target_lang=None` 的标准处理器已真实产出空 ASS 并返回成片成功。新增 source_caption 纯函数仅处理无翻译/同语种；有翻译请求但缺译文仍不得回退。模板和竖版路径不改。测试输入添加 0.5 秒静音尾段，避免 AAC/帧对齐截断源语音；这不是生产时间钳制或声学精确边界保证。

## 约束与停止条件
模型推理固定 CPU 小并发；避开线上加工。系统字体可读，宿主用户字体不映射；不能把本机样本测试称为普遍 ASR 准确率或平台交付。测试写入仅本次 sandbox。旧证据索引不覆盖改写。
