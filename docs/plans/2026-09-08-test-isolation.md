# 视频测试入口隔离计划

目标：测试收集、导入、默认 DAL 初始化和子进程均在一次性源码副本内执行；不加载正式 .env、不读写正式 output、不调用外部网络。

已确认：tests/conftest.py 收集前导入配置单例；Settings 使用源码根 .env；PipelineDB 默认路径绑定源码根，构造即迁移；PipelineManager 构造后替换 db/_OUT_DIR 仍晚于默认初始化；web.app 模块导入即构造默认 DAL。历史改 tmp_path 只保护后续锁路径。

依赖图：scripts/run_isolated_tests.py（标准库、git 文件清单、macOS sandbox-exec）→ 独立源码副本/.venv（仅依赖只读映射）→ pytest → tests/conftest.py → 原业务代码。业务代码不反向依赖测试工具，不修改数据库/FSM/配置单例的生产行为。

三道闸门：
1. 边界：只编辑测试入口、测试和文档；生产数据、.env、发布和服务不变。创建独立物理 worktree，合入前确认主干与流水线空闲。
2. 正交：隔离策略属于开发测试进程，不加入业务状态机或调度开关；不新增业务环境变量。runner 使用显式最小子进程环境，不读取继承的业务配置。
3. 复杂度：新增 runner 目标 ≤300 行；conftest ≤80 行；针对真实文件/网络/子进程边界编写契约测试，不继续向四千行 FSM 添加测试分支。

执行顺序：先探测操作系统沙盒可用性并验证拒绝生效；实现快照、配置清除、沙盒策略和收据；conftest 在任何业务导入前拒绝直接生产目录 pytest；先跑边界和 v7，再扩展收集/单测。所有失败须分类，不以跳过或隔离拒绝充作通过。

成功证据：操作系统对外部路径读写/网络及继承子进程的拒绝探针；默认 DB 和输出位于独立根；源码快照 SHA 清单；pytest 最终退出/统计；合入后同入口复验与服务状态回读。只读依赖由原 venv 提供，测试产物保留于独立目录便于检查。

停止条件：sandbox-exec 不可用、拒绝探针不通过、源快照包含越界链接或敏感路径即拒绝运行；不回退为裸 pytest。不为获得绿色结果自动调用上传器、模型、下载器或读取生产素材。

范围限制：这是测试入口的基础修复，尚不等于全量测试通过、跨平台沙盒、CPU/内存配额或 DAL/FSM 解耦完成。
