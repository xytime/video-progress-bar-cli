# 新闻精读卡片验收清单

> 适用于独立 MP4 支路；不接入发布流水线。任何一项未通过，均不得把成片标记为“可评审”。

## 0. 交付阶段

- [ ] **静态稿已确认**：只交付 1080×1920 PNG；此阶段不声称视频或动效完成。
- [ ] **动效稿已确认**：在静态稿确认后，才合成原片、唱片和逐词动画。
- [ ] **成片已确认**：视频、音频和 manifest 的检查均通过。

## 1. 内容与时间轴（自动阻断）

- [ ] `words` 时间单调、每个词均可与英文正文一一匹配。
- [ ] `paragraphs` 合并后的英文与逐词朗读正文完全一致；每段均有完整中文译文。
- [ ] 切点是完整语义单元：结尾不是逗号、连词、未完句或下一条新闻的导语。
- [ ] 最后学习词结束后仅保留 0.18 秒以内的收尾；不得播放未纳入正文的词。
- [ ] 右栏的词卡均来自正文标记词，且含英文、音标/词性（如有）和中文释义。

## 2. 静态版式（必须先人工看图）

- [ ] 画布为 9:16（1080×1920），无应用界面、黑边或多余外框。
- [ ] 首张模板的新闻红标、栏目大标题、副标题、红色信息条、左正文/右窄词栏栅格均存在且清晰。
- [ ] 原片小窗、唱片区、正文区和词卡区互不遮挡；正文的滚动阅读窗不覆盖固定头部或小窗。
- [ ] 正文使用粗黑英文；标记词是红底白字，词下中文注释在手机尺寸仍可辨认。
- [ ] 每个英文意群后紧跟完整中文段译；任何一段均不被裁成半句。
- [ ] 标记词小注不小于 22 px、中文段译不小于 30 px、右栏中文释义不小于 25 px。
- [ ] 中文字体为项目内 `SourceHanSerifCN-Medium.otf`；英文正文为 Avenir Next Condensed，词卡英文为 Baskerville。
- [ ] 对长正文，分别输出首屏、第一次滚动后、最后一屏三张静态检查图。

## 3. 逐词动效（成片必须自动抽帧核验）

- [ ] 在开头、中段、滚动后各选一个非红底词，在其语音中点抽帧：下划线必须可见且位于目标词下方。
- [ ] 每个下划线按本词开始/结束时间出现与消失；不得停留在上一个词或提前跳到下一个词。
- [ ] 下划线从左至右划出，长度随当前词进度增长；红底标记词也必须保留可见进度线。
- [ ] 滚动时下划线与其所属单词一起移动；滚动完成后当前词位于阅读窗的可读中区。
- [ ] 唱片在开头、中段、结尾三个抽帧的非中心标记位置不同，证明旋转真实发生。

## 4. 音视频与文件（自动核验）

- [ ] MP4 同时存在 H.264 视频和 AAC 原声；时长与 manifest 一致，误差不超过 0.15 秒。
- [ ] 音频结束不晚于“最后词结束 + 0.20 秒”；最后 0.08 秒有淡出。
- [ ] 原片小窗覆盖整个朗读区间；若为了测试而复制素材，manifest 必须标记为测试，生产片禁止复制拼接。
- [ ] 成片、timeline、manifest 和首/中/末抽帧一起留存；没有这些证据不得报告“已完成”。
