> 适用于独立 MP4 支路；不接入发布流水线。任何一项未通过，均不得把成片标记为“可评审”。

## A. 交付阶段与状态边界

- [ ] **静态稿已确认**：只交付 1080×1920 PNG；此阶段不声称视频或动效完成。
- [ ] **动效稿已确认**：在静态稿确认后，才合成原片、唱片和逐词动画。
- [ ] **样片已确认**：样片只用于版式、滚动、学习标记和音视频节奏验收；不得当作待发布成片。
- [ ] **成片已确认**：视频、音频、manifest、抽帧和内容切点均通过。
- [ ] **发布状态已确认**：只有平台后台可见或明确返回投稿证据时，才报告“已发布/已提交”；本清单本身不代表发布成功。

## B. 选题与素材边界

- [ ] 选题适合孩子观看：不使用偏政治、战争、暴力、极端灾害猎奇、争议性强的新闻。
- [ ] 原视频来源、标题、频道和截取区间已记录；如为测试样片，明确标注测试用途。
- [ ] 原片小窗采用 contain/top-aware 裁切，不截掉新闻标题、主播人脸、字幕条或关键信息。
- [ ] 如视频超过指定片段，必须只截取当前精读需要的完整语义段，不带入下一条新闻导语。

## C. 内容与时间轴（自动阻断）

- [ ] `words` 时间单调、每个词均可与英文正文一一匹配。
- [ ] `paragraphs` 合并后的英文与逐词朗读正文完全一致；每段均有完整中文译文。
- [ ] 切点是完整语义单元：结尾不是逗号、连词、未完句或下一条新闻的导语。
- [ ] 最后学习词结束后仅保留 0.18 秒以内的收尾；不得播放未纳入正文的词。
- [ ] 中文段译与英文段落一一对应，不允许只翻译半句或漏掉最后一句。
- [ ] 明确记录：总词数、逐词红线事件数、正文微笔记数、右栏词卡数、滚动次数、音频尾巴秒数。

## D. 生词与正文微笔记（必须单独检查）

- [ ] 生词候选已标明 1–10 级难度；默认仅标记 3 级（B1/PET）及以上的正文词。
- [ ] 对全文去重后，正文标记生词数 ÷ 可标记实词数不超过 25%；低于上限时优先保留更高难度词。
- [ ] 左侧正文微笔记池目标为 8–10 个；如果因文本太短不足 8 个，必须在交付说明里说明原因。
- [ ] 左侧正文微笔记必须实际出现在正文区：英文词有淡红标记，词下有中文小注；不能只在右栏出现。
- [ ] 多词短语必须完整标记，例如 `silver lining`、`evacuation orders`；小注只在短语首词下显示一次。
- [ ] 微笔记不得被红底反白、下划线、滚动裁切或右栏遮挡覆盖。
- [ ] 微笔记中文释义要短而准，避免重复词性（如 `vt. vt.`）和过早省略。
- [ ] 微笔记字号手机可读：词下小注不小于 22 px；中文段译不小于 30 px；右栏释义不小于 21 px。
- [ ] 首屏、中屏、末屏至少各抽一帧检查：若某一屏左侧完全没有任何学习标记，必须说明是内容分布导致，还是生词选择失败。

## E. 右侧核心词汇

- [ ] 右栏的词卡均来自左侧正文微笔记池，不能凭空新增正文没有标记的词。
- [ ] 右栏优先展示难度最高的 5 个词；长正文滚动时必须有兜底词卡，不能出现核心词汇区空白。
- [ ] 右栏词卡含英文、音标、学习级别/友好标签、词性和完整中文释义。
- [ ] 右栏词卡不得显示半张卡、顶部裁切卡、空白卡或只剩装饰线。
- [ ] 右栏与左侧正文不要求逐词严格同步，但必须与当前可见正文处于同一篇、同一学习词池。

## F. 静态版式（必须先人工看图）

- [ ] 画布为 9:16（1080×1920），无应用界面、黑边或多余外框。
- [ ] 首张模板的新闻红标、栏目大标题、副标题、红色信息条、左正文/右窄词栏栅格均存在且清晰。
- [ ] 原片小窗、唱片区、正文区和词卡区互不遮挡；正文的滚动阅读窗不覆盖固定头部或小窗。
- [ ] 正文使用粗黑英文；标记词为轻量红色学习标记，不得过重到压制正文阅读。
- [ ] 每个英文意群后紧跟完整中文段译；任何一段均不被裁成半句。
- [ ] 中文字体为项目内 `SourceHanSerifCN-Medium.otf`；英文正文为 Avenir Next Condensed，词卡英文为 Baskerville。
- [ ] 对长正文，分别输出首屏、第一次滚动后、最后一屏三张静态检查图。

## G. 滚动与逐词动效（成片必须自动抽帧核验）

- [ ] 在开头、中段、滚动后各选一个非红底词，在其语音中点抽帧：下划线必须可见且位于目标词下方。
- [ ] 每个下划线按本词开始/结束时间出现与消失；不得停留在上一个词或提前跳到下一个词。
- [ ] 下划线从左至右划出，长度随当前词进度增长；红底标记词也必须保留可见进度线。
- [ ] 滚动时下划线与其所属单词一起移动；滚动完成后当前词位于阅读窗的可读中区。
- [ ] 滚动次数不能过密；优先在自然段边界滚动，避免连续卡顿。
- [ ] 若使用右上影子跟读 Banner，需确认图片完整显示；若使用唱片机模板，需确认旋转真实发生。

## H. 音视频与文件（自动核验）

- [ ] MP4 同时存在 H.264 视频和 AAC 原声；时长与 manifest 一致，误差不超过 0.15 秒。
- [ ] 音频结束不晚于“最后词结束 + 0.20 秒”；最后 0.08 秒有淡出。
- [ ] 原片小窗覆盖整个朗读区间；若为了测试而复制素材，manifest 必须标记为测试，生产片禁止复制拼接。
- [ ] 成片、timeline、manifest 和首/中/末抽帧一起留存；没有这些证据不得报告“已完成”。

## I. 发布前最后确认

- [ ] 用户确认样片或明确授权使用当前样片继续生产/发布。
- [ ] 标题、简介、封面图已单独确认；不得把样片默认当封面来源。
- [ ] 发布前再次确认平台目标：视频号、抖音、快手等；没有明确要求不接入主流程。
- [ ] 发布后只报告可验证状态：本地文件、提交中、平台后台可见、已发布；不得把本地成功等同平台成功。
