## 首评已确认缺陷与修复

1. 同一视频在发布管理页和评论管理页返回不同 exportId，原代码直接比较，导致错帖误报。现保留账本原 ID，只以唯一、完整已发布文案绑定评论页场景 ID；截断或重复文案拒绝。
2. 原请求监听发生在请求发出后，无法真正撤回错帖。现增加网络发送前路由守门：同来源、同作品、完整同文才放行；否则中止。
3. 原评论列表没有限定作品，且把接口评论全当作者、允许正文前缀和虚构 ID。现绑定评论列表请求的作品 ID，并要求真实作者徽标、完整正文与唯一原生评论 ID 同时一致。
4. 真实 DOM 作者标记为 `.comment-author-bandage`，与旧选择器不符。现在由作者标记所属最小正文容器提取文本。
5. 置顶操作限定已确认的完整同文作者容器，避免全页第一个更多按钮。
