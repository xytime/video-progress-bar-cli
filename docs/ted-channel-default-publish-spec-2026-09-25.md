## 实施规则

1. 将启用时 `processed_videos` 的最大 `id` 记入 `TED_AUTO_PUBLISH_AFTER_ID`。默认值 0 代表关闭。只对 `id` 大于该边界、`source='AUTO'`、仍为 `PENDING` 且没有人工锁分的新视频，在自动评分时托底到当前演讲发布线 40 分。
2. 播放、点赞数据和原热度计算保留；日志说明托底前的分值。既有人工锁分、黑名单、`DISCOVERY`、源字幕预检、制作阶段审查及上传前审查保持原有行为。
3. 历史主视频及其切片不重新托底，并从正常加工和预加工两个自动候选入口排除；即使日后自然涨分也不会自动出队。历史素材另行讨论。
4. 托底只解决**评分资格**。候选仍可能因源字幕不可读、敏感命中、制作失败、发布队列积压、平台审核或其他原有门禁而未发布。本次不承诺平台已受理或公开可见。

## 验收

- 在隔离数据库中，边界后的两个精确频道的低热度 `AUTO` 视频评分达到 40，并出现在正常加工与预加工候选中。
- 边界前 TED 主视频及其切片即使涨到高分也不进入自动队列；其他频道、`DISCOVERY` 来源与人工锁分视频保持原评分和队列资格。
- 现有源字幕安全预检仍能在下载前阻断敏感样本；不新增任何审查绕过配置。
- 生产数据库只读核对边界前后数量；启用配置不直接修改任何既有视频行，不主动触发评分或投稿。

## 安全边界

现有政治与敏感审核规则和人工复核机制未因本次评分调整而改变。自动审核无法证明政治内容零漏检；若以后要求改变人工放行机制或加入逐条人工签认，应单独确认该安全流程的规格。
