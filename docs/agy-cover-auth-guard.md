# 封面后台 AGY 认证保护

2026-10-22，Codex；具体底层模型标识未知。

- 协调器在启动 AGY worker 前，以 `agy models` 和本次独立日志的正向认证结果预检；缓存模型列表本身不算认证成功。不读取或复制登录凭据。
- 封面生成及独立图片复核也各自预检。预检与实际 CLI 均由 macOS sandbox-exec 禁止执行 open、osascript、应用目录程序及 LaunchServices 打开操作。隔离器不可用时失败关闭。
- 认证检查失败时记录 `output/agy_cover_auth.json` 的 `AUTH_REQUIRED`，使用现有 Telegram 投递机制提醒人工登录。重复故障每日最多一次提醒，每五分钟重新检查一次，不自动发起浏览器授权。
- 人工在本机终端运行 `agy` 完成登录后，下一次检查自动恢复。后台不替用户操作授权页。
- 认证等待不计入生图尝试，也不打开供应商失败熔断。预检后认证失效同样记录 `auth_required`，释放任务 claim。
- 不延长任务原有截止时间。最终未恢复时，由现有队列规则交接 Luna / 本地兜底；不改变历史任务恢复、投稿或发布边界。
- 本修复覆盖封面队列的 AGY 生成与图片复核入口，不宣称所有其他 AGY 调用已受保护。

验证：隔离单测覆盖未认证阻止模型调用、无可信认证证据失败关闭、提醒合并、人工登录恢复、认证失效竞态、尝试预算和到期兜底。实机通过认证预检，并确认沙盒拒绝 `/usr/bin/open --help`，未发起授权或生成/发布任务。
