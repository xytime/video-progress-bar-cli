# 首页与 YouTube 关键词采集：用户验收及恢复说明

记录：Codex，2026-10-15。当前为交付核对单，**不代表完整验收通过**；实际开关、版本与作业证据以[上线记录](youtube-keyword-live-rollout.md)最新时间为准。

## 从哪里开始

本机首页：<http://localhost:9100/>。点击首页顶部或常用入口的 **YouTube 关键词采集**，进入 <http://localhost:9100/topic-candidates>。

新增关键词在该页右上角 **新建采集规则**。填写规则名称与查询词；类别用于限定选题方向，查询词才会送入 YouTube 搜索。可以指定发布时间范围、语言偏好、时长和有效期。保存默认不自动采集；首轮最多启用一条定时规则。当前验收使用已有“肺鼠疫”规则，不需新建规则或消耗更多试运行次数。

## 五分钟验收

1. 首页先看“建议先查看”：投递结果待核实、登录/恢复受阻、执行异常分别进入对应列表；返回后仍能找到关键词入口。“本地提交/完成”不代表平台公开成功。
2. 进入关键词工作台，核对顶部搜索、准入、预算及最近读取时间。若显示保护窗口、维护或配额限制，按所示原因处理；按钮禁用不能当作功能未实现。
3. 打开“新建采集规则”，查看查询词和类别区别，再取消，不提交测试规则。用鼠标悬停及键盘聚焦检查按钮文字是否清晰。
4. 查看“肺鼠疫”规则与候选，展开评分依据；高分但时长、内容或频道不合规的候选仍应显示受限。收藏只记录选题意向。
5. 查看“采集与刷新记录”。定时搜索、热度刷新必须有实际完成记录；自动准入必须能从候选关联到真实新主任务，不能只凭开关已开启判断成功。

## 故障关闭与回滚

**停止新关键词调用**：在工作台关闭达标准入和搜索，重新载入确认准入关闭、模式OFF；等待已经运行的作业自然结束，再检查预算与作业状态。关闭不删除候选、规则或累计预算，也不撤销已创建的主任务。

**源码修复回退**：保留现场所有并行改动，在隔离目录生成仅撤回本次变更的前向提交，运行相关隔离测试并保存最终整合清单。现场窗口允许且搜索/准入关闭后，用新的私有目录执行：

```sh
.venv/bin/python scripts/deployment_control.py plan \
  --directory <新的私有部署目录> --target <已测前向回退提交> \
  --tested-manifest <整合测试source-manifest.json> --preserve-keyword-profile
.venv/bin/python scripts/deployment_control.py apply --directory <同一新目录>
```

上述命令在生产根目录执行；参数必须来自当次实际准备结果。部署器先暂停接纳、自然排空，再检查来源/锁、备份、采用、维护启动和恢复。任何步骤失败，先执行 `status --directory <同一目录>` 核实现场；只有失败原因解除后才 `recover --directory <同一目录>`。不重放已完成计划，不编辑旧journal，不直接覆盖数据库。完成回读后，依据最新配额与窗口重新开启此前获准的功能；恢复失败则明确保留OFF。

本轮只允许累计最多1条达标准入，不自动延长规则、不降低75分、时长或内容要求，不扩大外部发布授权。规则到期且无达标候选时，应将“采集功能可用”和“真实准入尚未验收”分别报告。
