# 原字幕语义核验提速续作（2026-10-31）

作者：Codex。范围属于已批准的完整证据复用、语义核验及缓存优化；未改变字幕质量、选题或发布规则。

## 已实现

原先单段超过 21 组中文 OCR（再加首中尾三图）时，会在整片 OCR 完成后直接抛出 `VISUAL_REVIEW_BUDGET_EXCEEDED`，一次语义请求也不执行。

新路径由独立默认关闭的 `NATIVE_CAPTION_SEMANTIC_PAGING_ENABLED=false` 控制：

1. 全部疑似中文按原有文字/位置分组，每页最多 21 组，附原分辨率实际帧及首中尾。每组必须返回视觉分类、逐字核对及理由，不能省略低置信度组。相同源帧的多个 OCR 框共用一张原图；不同帧不做近似合并。
2. 所有页都清楚、完整后，使用完整 OCR 时间区间、整段对白、所有页证明和上下文图进行整段语义核验。任一页不确定、缺失、编号不符、视觉与语义矛盾均拒绝。发现对白中文时禁止返回 ABSENT。
3. 保留原宿主置信度 ≥ 0.50、帧覆盖 ≥ 95%、最大连续空隙 ≤ 250 ms，以及部分中文字幕进入复核的规则；没有以抽帧判断整片无中文字幕。已有完整中文的保留规则、横屏布局限制不变。
4. 核验图片按源 SHA、OpenCV 编码契约和图片字节摘要保存；恢复时无需重新解码取图。坏图重建、错源失效、同源图片缓存写入互斥、源中途变化撤销混合 manifest。
5. 单个超量段所有分页和最终核验共用原配置 120 秒累计时限。执行前持久预扣；进程硬退出不返还未知占用。预算身份不含模型和分页提示词版本，不能通过换模型或合同重获额度。已有效缓存即使预算耗尽仍可读取，未完成请求不会自动重试。
6. 普通未超限段的提示词、schema、图片编码和缓存合同不变。分页图片去重前的有效请求缓存也先精确查询并完整校验；未命中不会调用模型、删除旧缓存或新增供应商请求回执。

新增依赖均为单向：`router → caption_semantic_pages / caption_review_frames → caption_visual_pages / codex_text_provider / 既有纯累计账本 / settings`；`source_caption_contract → caption_visual_pages`。无 DB、上传器、外部消息或内容策略改动。
