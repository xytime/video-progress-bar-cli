# 生词片尾后台配置

2026-10-15 用户确认后实施。目标：按类型控制主流水线的生词片尾，并消除上游返回空生词后静默跳过的行为。

- 独立总开关和英语世界、华尔街、TED、AI 资讯、其他五类开关；初始全部开启，保留当前通用流水线行为。
- 识别顺序为内容类型、完整频道 ID、显式 AI 主题、其他。分类纯规则与商品共用，但配置文件和开关独立，修改不影响商品挂载或公众号文章。
- 配置在开始片尾步骤时冻结。已生成、上传中、已发布视频和冻结任务保持原决定；重试仍沿用原配置。历史有效片尾不回写、不重做。
- 每页三个生词，每页三秒，保持现有布局。正常从同一 ASS 中提取词卡；全片零词时对同一字幕执行一次有界经济型本地 Codex CLI 请求，宿主校验同段英中连续子串和英文完整词边界，拒绝跨段或编造释义。不引入付费 API 回退。
- 补提取失败、素材变更或片尾缓存损坏记录 FAILED 并阻止该步骤静默继续发布；只有当前源文件/字幕摘要绑定的“独立复核无合适词”结果允许明确不追加。
- 执行记录展示本地状态，不能冒充平台回读。后台提供草稿预览、最近任务和 CAS 保存，失败保留草稿。

调查发现独立英语世界学习卡不使用本片尾渲染器，它已有随片词卡、时长及音频 QA 契约。本次不改变该制作流程。五类识别适用于进入主流水线的任务，预览独立学习卡时显示“不经过此步骤”。

验收：各类型开关互不影响；配置关闭忽略该任务旧派生片尾；保存重启后可读；运行任务不被新保存改写；失败和空结果可区分；失效旧缓存不可发布；管理页保存/预览/冲突/失败/键盘/窄屏/主题验证。真实历史问题视频只在本地副本验证，不重新投稿。
