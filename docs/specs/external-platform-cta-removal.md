# 原片外部平台引导扣除：范围与技术评估

作者：Codex；日期：2026-10-10。用户授权评估并以 Daniel 真实视频制作独立测试副本；不设逐视频人工确认队列。本文记录技术推荐与待验证条件，不代表通用功能已上线。

后续用户已授权将可靠的原片首尾清理接入生产。[新版规格](ted-source-cleanup.md)仅自动复用完整匹配的已核验包装，不实现通用 CTA 语义识别，不按逐视频 ID 白名单设切点。未知布局、转码、正文导流和浮层保持原片；下文通用检测研究要求继续有效。

## 目标与边界

识别并提取原片中引导用户前往外部平台订阅、关注或访问账号的独立区间，在独立副本中扣除。YouTube/TikTok/Instagram 图标与账号组成的结束卡也属于候选，不能只查口播字幕。

正常谈论某平台、人物履历、讲者姓名、普通品牌标志、赞助鸣谢不能直接判为可删。“关注我们”等本项目文案不等于视频内原作者导流。二创导读、配音、时长、合成及自有互动引导完整保留。

2026-10-10用户反馈Daniel副本仍有残留，并授权这条从讲者站在台上开始。此样本修订删除原片首次讲话前的包装，以及末句、谢谢和短掌声之后的整段原片包装（包含赞助鸣谢与账号卡）。这项授权用于本条独立实验副本，不把所有赞助标志或正文品牌提及升级为自动删除条件。继续完整保护自有导读；本条未发现自有导读成片。

只针对未来新整片的原始素材准备阶段，放在字幕生成与二创合成之前。既有成片、章节片段、人工范围、历史发布不追溯加工；测试既有竖版只输出实验副本，不回写生产。

不确定、检测依赖不可用、异常和资源不足均选择原片并记明原因；不产生待人工确认任务。不调用付费服务，不安装复杂模型，不发布或重发。

## 性价比判断

| 情况 | 识别难度 / 删除难度 | 推荐 |
| --- | --- | --- |
| 独立静态片尾，平台图标与账号清楚，讲话已结束 | 中 / 低 | 优先研究并验证。OCR能找账号，仍需证明独立片尾、讲话结束与转场边界 |
| 独立片尾口播“订阅我的YouTube频道” | 中 / 低至中 | 可利用现有转录提取候选；只有完整独立句与可靠结束边界才能删除，否则保留 |
| 正文中插入独立宣传片段 | 高 / 中至高 | 本期保留；多次删段需要分段时间映射，字幕、章节、二创策划缓存同步重建 |
| 讲者讲话期间叠加账号、二维码或角标 | 高 / 高 | 本期保留；整段删去会丢失正文，去浮层会改变画面且需要新能力 |
| 正常提及平台、含平台名的案例或研究图表 | 区分语义难 / 不应直接删 | 关键词仅标候选，不能作为删除授权 |

推荐先验证**独立片尾**。沿用已安装的 Tesseract、Whisper、FFmpeg；不把现有开场完全音画摘要匹配方案扩展成逐视频片尾白名单。Daniel 的输入摘要固定仅用于重复实验与防素材误配，不能作为通用检测器。

OCR抽帧先定位候选，随后原分辨率复核，回看转场逐帧边界。账号、结束语、已验证的独立结束卡布局和可靠讲话保护必须联合成立；有一个条件不成立就保留。仅“Thank you”、一个“@”、沉默或固定最后N秒均不足以删片。本样本的917秒静态鸣谢锚点与918.44秒切点是样本证据，不推广到其他视频。

## 时间轴与缓存

片尾删去 `[end, duration)` 时，保留区间内时间戳不改变。没有任何字幕跨切点才可保留字幕字节；有跨界语句必须保留原片，不能机械截断。仅当前样本满足这一条件。

未来生产实施应在同一次原片准备中计算允许保留的 `[start, end)`；已验证的开场优化和片尾优化共用一次精确编码及素材收据，避免两轮原片重编码。开场不可靠可取start=0，片尾不可靠可取end=原时长，各自保守处理。

现有 `render_source_binding.py` 对 `speech_opening/<id>/` 路径有固定约束，不能直接追加第二条副本路径绕过绑定。接入前必须扩展相应素材/配方版本、保留区间、输出摘要及下游绑定，验证关闭开关、损坏缓存、就绪重试、二创策划复用始终选同一源与时间轴。不得只在最终竖版文件尾部截掉内容然后继续复用旧来源收据。

精确重新编码较简单，但会增加时间、空间与有损编码次数；未经证明不能用关键帧流复制替代。当前实验测量原片和竖版各一次独立编码用于比较，生产不应照搬两轮编码。各项成本见真实验证报告。

## 当前证据与研究停止条件

[Daniel 验证报告](../verification/external-cta-daniel-2026-10-10.md)记录第一版扣除4.53秒账号片尾的历史实验，以及用户指出首尾包装仍有残留后的修订。第一版不能作为用户清理目标已完成的证据。只有1条真实视频，不能据此报告检测准确率或自动上线成熟度。已有TED开场漏剪问题仍独立存在，不因指定样本可裁剪而改称已修复。
