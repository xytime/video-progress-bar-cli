# TED/TEDx 原片首尾包装自动清理

作者：Codex；2026-10-10。用户已授权接入生产，无产品二次确认和逐视频人工审核。本规格补充原开场规格，保留此前历史验证结论。

## 范围与保护

仅处理 TED/TEDx 新整片的原始下载素材，先于字幕、基础竖版和二创。删除已核验的品牌、赞助商、账号包装；不判断主持人介绍是否必要，不处理短问候后的掌声、半句话、正文导流、浮层或二维码。所有人声均保护，声音先于画面也不追切到讲者出现。

二创导读的文字、音频、时长及完整合成保持。已有基础成片优先采用原来的有效素材绑定，即使旧收据存在、配方升级或开关关闭，也不重新清理。无绑定的历史成片沿用原片。坏绑定不覆盖其加工副本，返回原片交给既有质量检查处理。章节、人工范围及历史发布不扩大处理范围。

## 稳定规则

新入口为 `processors/ted_source_cleanup.py`，配方 `ted-source-cleanup-v1`。以完整原生视频帧、所有声道解码音频及流参数的 SHA256 精确匹配已核验包装；不依赖视频 ID、标题、OCR、角色、语义或 VAD 概率。参考编号只用于追溯。已核验的包装不能含讲话或正文画面；对声画加入讲话、文字或任何改动都会失配。

新目录 `resources/ted-source-packaging.json` 登记 NorthernQuarter 的开头21.04秒和尾部7.72秒；沿用六段已验证品牌前缀。两端独立决定：未知开头取0，未知结尾取原时长。只剪精确命中端。它是窄范围的包装复用功能，不能称通用 TED 片头/结束卡识别。不同转码、掌声和音轨变化均可能漏剪，接受保留；不靠放宽匹配换覆盖率。

源音视频起点需有限且接近零（≤1ms），视频末端与容器时长差≤150ms。尾部起点按视频流末端减模板长度，不能直接拿容器长度减同一常数。Daniel 实际保留 `[21.04, 915.20)`，仅覆盖公共包装的模板排除讲者淡入/淡出帧。舞台渐变保留：比人工样本多保留约1.48秒，不追切进首末讲话。

## 一份素材、一次编码

两个边界共用一次精确编码，副本仍放在 `speech_opening/<id>/<id>.mp4`，满足既有来源绑定约束。原片不覆盖。先完整解码验证候选，再原子替换副本；零起点与音视频绝对末端校验沿用旧契约。检测异常、编码失败、原片变化、磁盘不足或收据不可写均自动选择原片，收据或流水线日志记录原因；不创建人工任务。

收据沿用 `.opening.json` 文件名，新增结束边界、配方、两份模板摘要、原片/副本摘要和时长、字节与耗时。只有全部指纹及有限边界、媒体时长一致才能复用；损坏收据或副本重新从原片检测，失败收据可重试。字幕从实际选定素材生成，零起点 ASS、基础竖版及二创始终使用同一绑定；不在最后成片另剪一次。

编码保持 libx264 veryfast CRF18/2线程、AAC192k，保留当前额外编码及绑定副本成本。可用空间不足512MiB或原片字节的3倍时回退；这是保守起步门槛，不承诺编码大小上限。子进程由既有独立进程组跟踪，外层1680秒有界超时；内部检测、编码和解码分别有时限。硬重置及 TTL 沿用原目录保护规则。

## 开关、运行采用与验收

`ENABLE_TED_SOURCE_CLEANUP` 默认false，真实验证后生产显式true；启用后替代旧开场入口。只关闭新开关会恢复原有开场规则；两个开关均关闭才完全禁止新自动清理，历史有效绑定仍固定。统计 API 的 `source_preparation` 回读当前服务进程实际开关与配方，不能只凭文件或新进程 PID 宣称生效。

验收分别记录真实原片检测及首末讲话对照、合成故障/全流程编码回归、Git主干交付、运行开关回读和生产入口的隔离输出。模板参考条目不算留出集；单条结尾命中不证明泛化准确率。上线不触发发布，也不把试验处理当自然生产任务。具体证据、成本及后续研究以验证报告为准。

## 后续研究

| 工作 | 当前处置 / 缺少证据 | 后续验收 |
| --- | --- | --- |
| 多活动结束卡、不同转码 | 未匹配端保留；当前尾模板仅1条参考 | 至少3个活动、20条独立留出视频，10正10反；标注完整首末人声、重要文字，逐条记录误删/漏剪和成本；真实误删为0，仍不能由数量宣称统计准确率 |
| 跨视频包装复用 | 只匹配完整音画；音轨和编码差异导致漏剪 | 独立同活动视频确认匹配区间只含公共包装；改变任意声道讲话或重要文字必须保留，禁止以逐视频切点白名单代替通用检测 |
| 讲话与转场更贴近边界 | 保留舞台渐变及掌声，不追求极限切点 | 标定弱声、先声后画、无声演示和重要文字的反例；保护所有音素及正文画面后再评估 |
| 正文导流 / 浮层 | 保留；缺可靠语义边界及多段时间轴映射 | 真实反例、完整句与画面保护、字幕/章节/二创和重试映射全部通过，再单独评估 |
| 编码和存储 | 保留单次精确副本；绑定缓存不提前删除 | 多时长/帧率比较总成本；减少编码或回收须证明同步、首字和历史绑定不受损 |
| 自然新任务观察 | 不重制历史、不新增投稿 | 后续自然新整片回读处理收据、素材绑定、字幕及二创；加工、平台受理、公开播放分开记录 |
