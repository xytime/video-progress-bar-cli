# TED/TEDx 原片开场等待优化

作者：Codex；2026-10-09。用户已授权直接实施，无人工确认环节。

## 已确认范围

目标：删除原始演讲视频首次讲话前的连续等待，二创导读片头完整保留。
只覆盖明确 TED/TEDx 频道的新整片加工；已有成片、人工范围、章节子片段保留。
主流水线章节切片优先执行；若产生章节任务，不进入整片去等待。
主持人或旁白同样算讲话，第一次问候后的掌声保留，半句话起点不处理。

依赖图：`pipeline_manager → speech_opening → video_metadata/config`；
`pipeline_manager/insight_editorial → render_source_binding`。核心域不反向引用。

## 确定性处理

固定 v5.1 离线 Silero VAD，CPU 单线程，16kHz 单声道，检查前30秒。
首次概率≥0.2 的疑似讲话即保护边界；其后0.5秒内出现连续三帧≥0.8才确认。
切点在保护边界前0.5秒；删除不足2秒则不剪。早期含混人声、无可靠讲话、
音轨/模型缺失、超时、编码及校验失败均自动保留原片，落盘原因，不等待审核。
这些阈值是保守初值，模型概率不代表已校准的正确率。

原片保持不变。精确编码独立素材副本，按副本重新生成字幕，全部时间从零开始。
目前多一次原片编码，以换取简单、准确的音画起点；不使用关键帧流复制冒充精确裁剪。
来源、模型、配方、副本摘要绑定检查点，临时失败不永久缓存。
基础竖版与副本/字幕再绑定摘要，二创、发布预检和重试使用同一时间轴；
规范 ASS 副本保留给既有字幕审查与证据归档。
默认 `ENABLE_TED_OPENING_TRIM=true`；关闭时回到原片加工并使不匹配缓存失效。
不生成新投稿，不重发历史视频。

## 验收边界

覆盖真实离线模型、已维护的合成语音夹具、实际 FFmpeg 编码/全片解码、
首字保护、原片不变、检查点复用、坏副本重建/回退、二创时间轴和历史任务保护。
合成语音验收不代表真实 TED 音乐/掌声/弱人声识别准确率或留存率改善。
无声内容无法由音频判断；疑难开场的自动安全识别列为后续研究，不增加人工确认。

## 后续研究任务

| 任务 | 当前处置 | 研究验收 |
| --- | --- | --- |
| 无声演示、开场重要文字的保护 | 音频方案无法识别；首版不扩展视觉理解 | 本地代表性样本证明不会误删有效视觉内容，再评估是否启用视觉保护 |
| 音乐/掌声/含混弱语音 | 出现疑似语音即保留；记录原因 | 建立真实开场标注集，量化误删与漏剪，不凭少量成功样本扩大范围 |
| 主持人交接及必要背景 | 从任何人第一次讲话开始保留 | 角色与语义保护经独立验证，收益覆盖新增成本 |
| 问候后长掌声 | 全部保留 | 短问候及语义关联有可验证识别规则后再考虑 |
| 额外编码成本 | 先用精确编码独立副本 | 在字幕、二创、章节和重试保持同步的前提下评估合并最终编码 |
| 非 TED 来源、章节及人工范围叠加 | 不自动裁剪 | 定义明确适用条件与唯一时间映射，避免重复裁剪 |

半句话起点不列入本次修复目标。研究任务仅留档，未创建自动化或另一个聊天。
