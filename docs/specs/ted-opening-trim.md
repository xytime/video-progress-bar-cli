# TED/TEDx 原片开场等待优化

作者：Codex；更新：2026-10-09。用户已授权调查、修复、测试与主干交付，无人工确认队列。

## 业务范围

只优化原始 TED/TEDx 新整片第一次讲话前的等待。主持人、旁白、演讲者的第一次讲话均受保护，不识别角色、不判断介绍必要性。短问候及随后掌声保留；半句话起点不处理。声音先出时保护声音，不追求更早看到讲者。
二创导读的内容、音频、时长及合成逻辑完整保留。已有成片、章节子片段、人工指定范围不扩大自动裁剪；章节切片优先。原片不得覆盖。不下载额外模型、不调用付费服务、不发布或重发内容。

## v2：先证明前缀可删，再精确裁剪

v1 只有音频保护。真实素材检查发现，主题或讲者信息可能只出现在首次讲话前的卡片中。因此 v2 收窄为**完整解码音画与已验证品牌前缀完全一致**时才可删；其他开场自动保留。模板更新属于版本验证，不是逐视频审批。

1. 固定离线 Silero VAD v5.1、CPU单线程、16kHz单声道，检查前30秒；模型摘要必须匹配，含缓存复用。
2. 首次概率≥0.2即保护；随后0.5秒内有连续三帧≥0.8才确认。声音边界前留0.5秒，收益不足2秒不剪。阈值不是准确率。
3. 核对源音视频起点有限且接近零（≤1ms）；未知时间基保留。
4. 从本地 `assets/models/silero-vad/verified-prefixes.json` 的六段已核对品牌前缀中查找匹配：原生完整视频帧、全部声道解码音频 SHA256，以及尺寸、像素格式、帧率、采样率、声道数必须匹配。不缩图、不抽帧、不做模糊相似度/OCR/语义判断。不同转码也可能不匹配，接受漏剪。
5. 最终切点取“匹配品牌区间末端”和“音频保护切点”的较早值。品牌之后的舞台等待、掌声、文字和演示保留。无匹配返回 `UNVERIFIED_AV_PREFIX`。
6. 独立副本精确编码（libx264 veryfast CRF18、2线程、AAC192k）；不使用关键帧流复制代替精确切点。总时长误差≤150ms，音视频起点距零≤50ms，绝对末端差≤80ms；检查有限数值。绝对末端=起点+时长，不比较两条流时长冒充末端。
7. 编码、资源、模型、校验等异常自动使用原片，记录原因和 `failure_code`。临时异常下次重试，确定性保留可缓存；目录/收据无法写入时由流水线日志记录并保留原片。无可靠讲话或无声内容保留。

## 单一素材与时间轴

`pipeline_manager → speech_opening → video_metadata/config`，符合依赖方向。源、模型、配方v2、模板摘要、副本摘要绑定检查点；v1正向结果不能跨配方直接复用。
字幕从选定素材重新生成。竖版、原片副本和零起点ASS再绑定摘要；二创输入解析、就绪预检与提交重试读取同一绑定，坏绑定拒绝混用未裁剪原片或旧字幕。绑定了裁剪素材但缺少策划指纹的旧V2二创脚本须重建；正常手工脚本行为保留。

`ENABLE_TED_OPENING_TRIM=true` 沿用现有默认值。关闭后新加工选择原片并使不匹配竖版缓存失效；已就绪任务仍使用其已验证绑定，避免修改成片的时间轴。不会触发历史任务重制或新投稿。

## 验收与限制

以[当前验证报告](../verification/ted-opening-trim-2026-10-09.md)及逐样本JSON为准。30条真实开场是目的性样本，其中六条也是模板参考；不宣称独立准确率、泛化覆盖率或留存率提升。真实剪裁副本与源保留区间的首词ASR及波形一致性只是保护证据，不能替代人工音素标注。

保留一次独立编码：当前实测完整11分钟原片约29秒额外处理、约67.4MB副本。先保持统一素材和精确时间轴；没有充分收益证据，不将裁剪合并进最终编码。

## 后续研究清单

| 研究任务 | 当前处置与缺失证据 | 未来验收标准 |
| --- | --- | --- |
| 更多事件/转码的品牌前缀 | 未知或不完全匹配保留；目前只有六个登记前缀 | 独立事件、不同编码的留出集，包含新增文字/弱声/替换画面反例；错误删除为0，记录漏剪、耗时及模板维护成本后再扩展 |
| 弱人声、音频先出、黑场转场 | 未登记前缀保留；有合成扰动及边界测试，缺少独立真实音素标注 | 真实多语种、低音量、噪声及音频先出素材分别标定第一音素；明确标注误差，不用模型概率充当准确率 |
| 无声演示与独有重要文字 | 未匹配音画保留；真实音乐表演和两条开场卡已验证保留，纯无声演示真实集不足 | 建立演示/文字真实留出集及具体有效视觉区间；在原有离线依赖下可靠保护，否则继续保留，不引入复杂理解 |
| 编码与存储优化 | 当前精确副本；完整成本仅测一条 | 多种帧率/时长真实整片比较总编码、磁盘和缓存成本；首字、字幕、二创及重试映射不变，收益明确才实施 |
| 新任务完整运行证据 | 本轮验证代码采用，不触发下载、生成付费内容或发布 | 自然到来的授权新任务只读核对素材绑定、字幕及二创收据；加工、平台受理、公开播放分别记录 |

主持人语义分析、问候后掌声删除、半句话修复不属于本轮目标。研究仅留档，不创建另一个Goal、聊天、自动化或人工审核队列。
