# 视频预筛选 v1

日期：2026-10-21（Asia/Shanghai）  
方案整理：Codex，具体模型版本未知。  
状态：用户已确认业务范围与静态页面，并授权开发；运行采用另行核实。

## 已确认范围

在选题中心增加独立“视频预筛选”tab；手动检索、保存多套配置、仅做人工预筛选，复用 YouTube 官方 Data API。不新增 yt-dlp 检索引擎。

本文件保存本轮已确认的系统方案，不覆盖既有关键词采集、定时调度、评分或生产准入方案。静态页面已确认；本轮在隔离工作区开发、验证，不更改生产搜索门禁。

## 页面与工作流

选题中心 → 视频预筛选 → 选择或编辑规则 → 保存配置 → 手动开始检索 → 查看结果 → 收藏或排除。

页面上方说明“仅保存选题意向”，显示规则选择、参数与保存状态；下方是本轮结果、筛选摘要和历史检索入口。默认展示合格结果，可切换未达标、资料不足与全部候选。结果不展示生产提权或发布按钮。

保存和执行分开。保存、打开页面、刷新和切换规则均不触发搜索。未保存修改时提示先保存；保存失败或版本冲突保留草稿。正在执行时禁用重复启动，显示真实阶段与数量，不伪造百分比。

## 参数

| 参数 | 默认 | 规则 |
|---|---|---|
| 规则名称 | 人物与科技快讯 | 可保存多套规则 |
| 关键词 | Elon Musk、Jensen Huang、plague | 每行一个短语，任一匹配；提交时转换为官方 API 查询语法；不自动扩词 |
| 回溯小时 | 48 | 以作业启动时刻冻结 UTC 起止区间 |
| 最长时长 | 300 秒 | 0 < duration ≤ max_duration；不设额外最低时长 |
| 最低播放量 | 10,000 | views ≥ min_views |
| 最低点赞率 | 1.5% | likes ÷ views ≥ threshold；显示百分数，内部保存比例 |
| 候选数量 | 50 | 建议首版 1–50；是请求上限，不保证取满或全站覆盖 |
| 排序 | 播放量降序 | 全部筛选完成后、分页前排序 |

实现校验范围：规则最多20套；回溯1–720小时、时长1–1800秒、播放量0–10^12、点赞率0–100%、候选1–50。关键词1–10个、每个最多80字、合并查询最多450 UTF-8字节；同规则检索间隔15分钟。初版不加入复杂布尔表达式编辑器。

## 数据与边界

- 使用官方 search.list + 批量 videos.list。搜索按近期候选召回，再按详情筛选和本地排序；不是全站热度榜。首版不自动翻页补足 50 条。
- 不用 videoDuration=short 代替 300 秒规则，避免漏掉 4–5 分钟视频。
- 时间窗口采用 [started_at - lookback_hours, started_at]；缺少精确时间不以日期零点冒充，标资料不足；未来时间不合格。
- 未开播、直播中、回放处理中或状态无法确认不进入合格列表；缺失时长、播放量、点赞数或必要来源字段标资料不足，缺失不当作零。
- 统计仅为 fetched_at 时刻观测；北京时间展示，保存 UTC。收藏不承诺持续满足相对时间窗口，历史结果标明检索区间与获取时间。
- 记录规则版本与参数快照、候选源身份、指标、命中/未达标原因、检索阶段和失败原因；同一视频跨规则去重，保留命中关系及既有收藏/排除决定。
- 沿用黑名单与内容策略检查；数值达标不代表通过业务审查。展示指标与规则受限原因。
- 预筛选记录使用明确用途标记并在后端禁止自动准入。与既有自动规则共同命中时，仅既有独立准入规则可授予生产资格，预筛选或收藏不得新增这种资格。
- 不使用旧高赞页 promote 接口；不新建 processed_videos 任务，不自动制作或发布，不更改现有调度、门禁或配额上限。
- 复用搜索锁、持久预算、超时与错误处理；配额不足、搜索关闭、资料失败和真实零结果分别展示；失败保留旧结果并明确标旧，不能冒充本轮成功结果。

## 验收

1. 新建、编辑、保存、切换配置并刷新后可恢复；仅点击开始检索产生外部请求。
2. 精确验证 48 小时边界、300/301/0 秒、播放量等值、点赞率等值与缺失数据；精确筛选在分页前完成。
3. 50 为候选上限；显示实际返回数、完成详情数、合格数、未达标数、资料不足数和失败数，数量口径互斥且可解释。
4. 同一视频跨关键词/规则不重复建立候选，收藏及排除不被重搜覆盖。
5. 搜索、保存与收藏均不增加生产任务、不调用发布器；既有关键词采集与自动准入通过回归验证。
6. 隔离单元/API 测试与浏览器任务验证覆盖成功、空态、部分失败、完全失败、重复提交、配置冲突、键盘和窄屏。
7. 页面确认后才进入实现；测试通过、代码提交、运行采用和真实 API 回读分别记录。
