# 单条二创后发布提示词

作者：Codex；2026-10-08。

复制以下内容，替换视频和目标平台/账号：

> 请将【视频链接或本地路径】制作成已确认的“财经编辑风格”二创视频，并发布到【平台／账号】。
> 本次只发二创 B 版，不额外发布普通 A 版。
> 保留完整原片、原声和双语字幕，加入有原文依据的导读、六条洞察和片尾思辨问题，
> 画面与配音都加入“欢迎在评论区说说你的判断。”
> 使用已确认的暖白、墨黑、铜色版式，人物、字幕、洞察分区，沿用真实品牌标识与视频号码。
> 普通事实疑点先尽量修正并留档，不因此停止发布；沿用现有内容审查与媒体质量检查。
> 复用可验证素材，制作失败不得用普通版冒充二创版；如已在 A/B 实验中，复用对应 B 记录，避免重复发布。
> 本次授权完成制作、封面文案、平台检查及发布提交。完成后给我成片、平台作品 ID／可用链接和回读状态，
> 明确区分已提交、审核中和已公开；已有成功记录则直接返回，不重复发布。

不填写平台/账号时不能推定新目的地；执行者应先核对既有发布路由，仍有歧义再询问。
此文档是可复用提示词，不代表用户已经授权发布某条未指定的视频。
