# 商品配置中心实际部署记录

维护：Codex · 2026-10-11

## 已上线

生产主干的 9100 控制台首页顶部新增「商品挂载」，地址 http://localhost:9100/product-settings 。五类首选/备选、全局默认、频道识别条件、最近 100 条待发布任务预览、保存与并发冲突校验均可操作。

真实 Chromium 已验证五类渲染、英语世界预览、保持全部原选品偏好的保存与重载、桌面/手机显示，无页面脚本错误。隔离测试 97 项通过；HTTP 四个相关入口均为 200。证据见 receipt.json 与页面截图。

## 尚未接入

当前发布器继续使用原有硬编码商品策略。此页面保存五类配置，但配置尚未用于实际发布；API publisher_connected=false，页面与保存提示明确展示这一事实，不能把保存成功理解为挂载生效。

本次未替换上传器、商品选择执行器、浏览器商品适配器或发布上下文入口。旧 choose_product_role / get_verified_product_catalog 接口及原校验保持兼容。此前候选分支 codex/wechat-product-config 的严格身份回读与发布集成仍需真实平台验收后单独收敛；本次不是该分支的完整合并。

本次仅常规重启控制台使路由生效，没有手工触发测试视频发布或操作真实视频号商品列表。既有调度器按原有生命周期恢复运行。控制台上线、配置保存和真实平台挂载是不同验收阶段。

## 使用

进入商品挂载设置 → 修改对应视频类型的首选/备选 → 选择视频预览 → 保存配置。可先准备配置；待发布器正式接入后才影响选品，当前页面会持续显示未接入。

当前默认：英语世界/TED→思考快与慢；华尔街→股市趋势技术分析；AI→维特根斯坦；其他沿用财经/新闻细分，否则全局默认思考快与慢。商品完整名称与 ID 显示在选择框下方。
