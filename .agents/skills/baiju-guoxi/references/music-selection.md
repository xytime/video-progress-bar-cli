# 白驹过隙：配乐选择与试听

每次新主题都执行本规范。目标是让真实照片的年代跨越产生情绪和记忆点，不能用一条「有声音、卡上点」的背景填满时长。

## 已确认的失败与边界

2026-10-16，用户明确评价《算力时代的三张面孔》的背景音乐「毫无吸引力」「没有借鉴成功的一些经验」「甚至还不如上一次」，要求固化技能，明确不重做本条视频。

该片采用《制造·加速·重塑 — 原创配乐》（Codex 程序作曲与编曲）：合成和弦、循环低频脉冲、钟声音型和三次转场扫光。现有制作记录只提供合成元数据与响度、峰值、时长检查，没有真实成功案例对照或用户试听选择记录。不能把这些技术记录包装成音乐审美验收。

这是用户确认的负面样本，不得换文件名、改音量后作为下一主题默认音乐。用户所指「上一次」的具体音轨尚未确认，不编造其曲名或偏好；需要比较时读取最近真实交付及反馈，无法确定就标为未知。

## 1. 参考案例先于选曲

- 先看用户明确喜欢的既有作品，再找通常两个与题材、目标受众或今昔揭晓结构相关的真实案例。记录原始链接或本地文件、具体时间段、能借鉴的音乐安排。
- 新搜案例需查看真实页面和实际声音，不根据标题、搜索摘要或他人描述声称已经听过。若称「成功案例」，记录可核验的依据：用户明确肯定，或页面可见的播放/互动数据及查看日期。没有这些依据则称「风格参考」，不宣称音乐导致高播放。
- 提炼可迁移的做法：开头如何抓耳，哪一段旋律或声音唤起时代记忆，揭晓时如何抬升或留白，结尾怎样收束。借鉴音乐组织方式，不直接把别人的整条音轨复制过来。
- 已有 `assets/baiju_guoxi/football/football_deck.json` 等配置可帮助寻找标志乐句；其文字自评、文件存在和发布记录本身均不能证明用户喜欢或传播成功。

## 2. 候选必须比较具体段落

通常准备两种有实际差异的候选，并明确推荐一条；用户已给出曲目、段落或选定音轨时优先执行其选择，不机械增加候选数量。

- 按主题寻找可辨认的旋律、时代质感或情绪动机。科技人物也需要有记忆点的音乐，不因题材是科技就默认「低频脉冲＋电子铺底」。
- 开头约 0–2 秒应有可感知的吸引点，可以是标志旋律、人声、节奏或有意的悬念；不能让大半条短片都在等待前奏结束。吸引力不等于更响、更密或一直高潮。
- 人物早年到晚年的揭晓应有乐句、力度或配器变化；不要求每次切转都堆扫光和重击。高潮应有铺垫和落点，尾句自然结束。
- 先选择好听的具体段落，再对齐画面。无明显旋律发展、动态单一、反复循环的占位音轨不进入推荐；「原创」「史诗」「致敬某大师」不是质量依据。
- 使用有明确使用依据的音乐、平台授权曲库或合适的原创制作。知名歌曲可供研究，但曲名、署名或短时截取不等于公开使用授权；授权不明时继续寻找可用候选，不静默降级为程序音色填充。

## 3. 渲染前交付能听到的提案

在提供照片静态提案的同一轮，附候选的真实可播放选段：通常每条 12–15 秒，覆盖开头和至少一次今昔揭晓。标出计划使用的曲目、原曲起止点和推荐理由。可以使用静态照片配音频的轻量试听；不为试听先渲染完整视频。

本地音频用绝对路径显示：`![候选 A 试听](/absolute/path/candidate-a.m4a)`。只有曲名、音乐风格描述、波形图或音频网页链接不能代替实际试听；工具若无法听音，不声称已经听过，交付真实样音由用户判断。

同一条消息让用户确认「静态方案＋推荐配乐」，减少往返。静态图批准不能自动视为配乐批准；只有用户已经听过并选定音轨，或本轮明确授权沿用某条已试听音乐，才完成音乐确认。不要对已有明确选择反复索要许可。

## 4. 决策与成片核对

本主题保存简短 `music_review.md`，记录：

| 项目 | 必需证据 |
| --- | --- |
| 参考案例 | 链接/路径、时间段、可借鉴安排；成功依据或「风格参考」标记 |
| 实际候选 | 曲名、作者/来源、使用依据、可播放样音、选段起止 |
| 推荐 | 对开头、年代揭晓、情绪推进、结尾的具体判断与取舍 |
| 用户选择 | 用户确认原话或可靠消息引用；未确认时为 `PENDING_LISTENING`，明确否定为 `REJECTED` |
| 最终音轨 | 选定后为 `USER_APPROVED`，登记文件绝对路径、SHA-256、使用段落及关键画面切点 |
| 成片检查 | 音轨与确认版本一致；实际音画回放；另记响度、峰值、时长等技术结果 |

不得用自行打分代替用户试听。现有渲染器的音量和去重检查不会验证本文件，这是一项制作执行要求，不宣称已经新增了自动代码闸门。

用户已批准后，渲染与普通混音自主推进。最终成片不得静默换曲、换成更平淡的片段或以重新合成为由覆盖选定版本；实质变更只重新确认受影响的配乐。用户只要求总结或固化技能时，不改旧片、不上传、不发布。
