# 竖屏布局规格与验收边界

画布为 1080×1920。以下是本项目的设计坐标，不是平台保证的安全区；不同设备、平台界面及长文案可能遮挡内容，成片仍需人工预览。

| 图层 | 设计位置 |
| --- | --- |
| ASS 字幕 | Alignment 8、MarginV 570；先原子高亮再 tag-aware 折行 |
| 原片画面 | x=0、y=656、宽1080、高608 |
| 栏目徽标 | x=780–1060、y=668–718 |
| 数据卡片 | x=50、y=1310、宽980、高240 |
| 底部预留 | y=1570–1920，不放核心文字 |

毛玻璃背景、徽标与裁切不提供去脸、去水印或敏感画面清除保证。人工批准制作前须逐段查看拟用镜头中的人物、台标、原字幕、图表与其他可辨内容；不适合使用的镜头须更换并重新提案。

制作后须检查多行字幕、长关键词、卡片数字和封面在实际手机尺寸下是否可读，确认口播完整、镜头衔接及音量正常。布局验收与事实核查、使用授权和平台审核是不同事项。
